# Аудит плана (/validate-plan)

Вход: `$ARGUMENTS` — путь к файлу плана (`planning/active/<slug>.md`).

Тонкая команда — БЕЗ субагентов. Только читает и печатает отчёт; план не правит — находки
уносятся отдельным ходом по скилу `fragmenting-plans-for-executors`.

## Шаги

1. Прочитать файл плана целиком.
2. Для каждого **открытого** (`- [ ]`) шага применить процедуру из
   `.claude/skills/fragmenting-plans-for-executors/SKILL.md` (раздел «Process», шаги 1–3):
   диагностический вопрос и проверку полей шаблона микро-шага (Целевой файл(ы) /
   Файлы-контракты / Границы / Задача / Критерий приёмки). Закрытые (`- [x]`) шаги не
   проверять и в отчёт не включать. Плюс три проверки того же раздела скила: экранный шаг
   ограничен макетом, а не формой API; поле реестра экранов (`docs/VISUALS.md`), чей
   экран-источник входит в веху, взято в схему или отложено записанным решением владельца; шаг,
   ждущий ответа владельца, — `БРАК`, пока обе ветки ответа не расписаны строками контракта.
3. Вынести вердикт по каждому открытому шагу — три формы и их семантика в скиле, раздел
   «Report the audit»; форма строки отчёта — в разделе «Форма отчёта» ниже.
4. Найти раздел `## Порядок исполнения`. Если его нет — отдельная строка отчёта
   `Порядок исполнения — БРАК плана целиком: раздел отсутствует`, и сразу к шагу 6.
5. Если раздел есть — проверить таблицу по четырём инвариантам (тот же скил, «Process» шаг
   4) и перечислить только то, что нарушено:
   - каждый шаг плана встречается ровно в одной строке;
   - `НЕДЕЛИМ` стоит в строке модели планировщика и первым в своём блоке;
   - в одной строке не больше пяти шагов;
   - параллельные строки помечены как независимые.
6. Закрыть отчёт счётом: `N шагов: X ОК · Y БРАК · Z НЕДЕЛИМ` — и ничем больше.

## Форма отчёта

```
<ID> — ОК
<ID> — БРАК: <причина> → <недостающая строка контракта>
<ID> — НЕДЕЛИМ (<модель>): <причина>
...
Порядок исполнения: ОК | <нарушения списком> | БРАК плана целиком: раздел отсутствует
Лимит: не больше двух проходов дробления на шаг.
N шагов: X ОК · Y БРАК · Z НЕДЕЛИМ
```

> Процедура и критерии живут в `fragmenting-plans-for-executors` — эта команда их исполняет,
> не пересказывает.
