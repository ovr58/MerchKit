# Как контрибьютить в Merch Kit

> Этот файл — **для людей**. Правила для AI-агентов (полосы доверия, consult-first, скилы)
> живут в [`AGENTS.md`](AGENTS.md); при расхождении по общим вопросам — ветвление, запрет
> прямых коммитов в trunk — прав `AGENTS.md`, он канон.
>
> Что за проект и с чего читать — [`README.md`](README.md).

## Перед первым коммитом: поставить хук

Локальный хук блокирует коммит в trunk. Git не переносит хуки при клоне — поставить надо
руками, одной командой:

```bash
cp githooks/pre-commit .git/hooks/pre-commit && chmod +x .git/hooks/pre-commit
```

Windows (PowerShell):

```powershell
Copy-Item githooks/pre-commit .git/hooks/pre-commit
```

Проверка: `git switch main` и попытка коммита должны отбиться сообщением
`ERROR: Direct commits to 'main' are not allowed.`

## Ветвление

Trunk — `main`. **Прямых коммитов и прямого push в `main` нет** ни у кого: локально это
отбивает хук, на сервере — защита ветки ([`docs/BRANCH_PROTECTION.md`](docs/BRANCH_PROTECTION.md)).

Имя ветки — префикс по типу работы плюс slug из 2–5 английских слов через дефис:

| Префикс | Для чего |
| --- | --- |
| `feature/<slug>` | новая функциональность |
| `fix/<slug>` | исправление бага |
| `exp/<slug>` | эксперимент, который может не дожить до мёржа |
| `claude/<slug>`, `harvi/<slug>` | ветки AI-агентов доверенной полосы (см. `AGENTS.md`) |

Пример: `feature/credit-packages-ui`, `fix/ledger-idempotency-key`.

## Коммиты

- Заголовок — в повелительном наклонении, ≤72 символов, без точки в конце: «добавь проверку
  баланса», а не «добавлено» или «фиксы».
- Один коммит — одно осмысленное изменение. Не смешивай рефакторинг с исправлением бага:
  ревьюеру придётся разбирать их глазами.
- Тело (после пустой строки) — **зачем**, а не что: «что» видно в диффе.
- Секреты не коммитятся никогда. Список исключений — [`.gitignore`](.gitignore);
  ключи Supabase и AI-провайдера живут в секретах Edge Functions, а не в репозитории.

## Pull request (запрос на слияние)

1. Ветка от актуального `main`, изменения по теме ветки и только они.
2. Перед PR прогнать локально то, что есть: `npm run build` и `npm test`
   (кода пока нет — команды приведены как контракт из `docs/SPEC.md` §7).
3. Открыть PR по шаблону [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md):
   цель, что изменилось, как проверял, риски.
4. Способ мёржа — `Squash and merge`: ветка приезжает в `main` одним коммитом.
5. После мёржа ветка удаляется (GitHub делает это сам).

## Ревью

- Ревьюер читает дифф, а не описание: описание объясняет **зачем**, дифф отвечает за «что».
- Замечание — с обоснованием и, по возможности, с предложением. «Не нравится» замечанием не является.
- Тред закрывает тот, кто его открыл, — после того как увидел правку.
- Автор вправе аргументированно отклонить замечание; молча проигнорировать — нет.

## Документы, которые надо обновлять вместе с кодом

Расхождение документа с кодом дороже отсутствия документа: на устаревший файл ссылаются как
на факт. Поэтому **в том же изменении**:

| Изменил | Обнови |
| --- | --- |
| поведение или требования | [`docs/TZ.md`](docs/TZ.md) |
| архитектуру, модули, данные | [`docs/SPEC.md`](docs/SPEC.md) |
| схему/референс | [`docs/VISUALS.md`](docs/VISUALS.md) — единственный визуальный артефакт |
| доменный термин | [`CONTEXT.md`](CONTEXT.md), словарь — [`docs/GLOSSARY.md`](docs/GLOSSARY.md) |
| дорогое к откату решение | новый файл в [`docs/adr/`](docs/adr/README.md) |
| план: создал/переместил | одну строку в [`planning/INDEX.md`](planning/INDEX.md) |

## Что важно не сломать

Три инварианта, нарушение которых стоит денег и доверия
([ADR-0006](docs/adr/0006-supabase-as-backend.md)):

1. **Баланс меняется только сервером** и только в одной транзакции с записью в журнал
   `ledger`; у каждой записи — ключ идемпотентности.
2. **RLS (Row Level Security — построчная защита доступа) включается в той же миграции, где
   создаётся таблица.** Публичный `anon`-ключ Supabase — не секрет by design; данные защищают
   политики, а не маршруты интерфейса.
3. **AI-провайдер не вызывается из браузера** и не называется в коде напрямую — только через
   интерфейс `ai-provider` ([ADR-0005](docs/adr/0005-ai-provider-abstraction.md)).
