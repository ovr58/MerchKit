# Подмножество CSS сочинения карточки — что переводится в слои

Шаг B1 плана [`html-layout-authoring_2026-10-05.md`](../../../planning/active/html-layout-authoring_2026-10-05.md),
ADR-0019 п. 5. Модель верстает карточку в HTML (скил-жанр `bench/html-probe/CARD_GENRE.md`,
раздел «Форма ответа»), Chromium снимает сцену (`extract.mts`, тип `HtmlScene` в
`supabase/functions/_shared/card-layout/html/scene.ts`), транспилятор переводит её в макет и
содержимое (`card-layout/html/to-layout.ts`). Словарь слоёв — `card-layout/types.ts`; он здесь
**не расширяется**: чего в нём нет, то записывается в раздел «Не выражается» и решается на B4.

## Как читается вёрстка

- **Геометрия — вычисленная, а не исходная.** Сцена снимает боксы `getBoundingClientRect` и
  стили `getComputedStyle`: Chromium уже разрешил единицы, наследование и раскладку. Поэтому
  `em`, `%`, `flex`, `inset` в исходнике транспилятору не мешают — они запрещены **формой
  ответа** (предсказуемость вёрстки модели), но не причина отказа (таблица «Запрещено»).
- **Сцена — в пикселях холста, макет — в долях.** Доли считает только `toLayout`: x и w — от
  ширины холста, y, h и кегль — от высоты, радиусы и эффекты — от меньшей стороны холста (так
  их читает сборщик `svg.ts`).
- **Слоем становится элемент одного из трёх видов**, остальное — контейнер без слоя:
  кадр (`img src="frame.png"`); элемент с собственным текстом (текстовые узлы прямо в нём,
  из вложенных элементов допустим только `<br>`); элемент без текста, но с видимым фоном,
  рамкой или тенью. Контейнер без собственного вида (`div` с `flex`, обёртка позиционирования)
  слоя не даёт — его дети снимаются как обычно.
- **Строки текста — по `Range.getClientRects`:** каждая буква обмеряется, буквы группируются в
  строки по вертикали. Как Chromium перенёс текст, так строки и лягут в слой (`lines` или
  строки содержимого привязки) — сборщик сам не переносит.

## CSS → слой

Одна строка — один способ. «Доля Н» — доля высоты холста, «доля Ш» — ширины, «доля min» —
меньшей стороны холста.

| № | CSS | Слой и поле | Правило перевода |
| --- | --- | --- | --- |
| 1 | `#card` (`position:relative`, `width`/`height` в px) | холст `canvas` | `aspectW:aspectH` = W:H; `background-color` `#card` → `canvas.background` solid, прозрачный → `#ffffff` |
| 2 | `img src="frame.png"` | `frame`, `bind: {kind:'frame'}` | бокс элемента долями (обычно 0/0/1/1); `object-fit` → `fit` (`cover`/`contain`); `object-position` только `50% 50%` |
| 3 | `border-radius` у кадра | `frame.radius` | px / меньшая сторона **бокса** кадра (`Rounded` в `types.ts`) |
| 4 | элемент без текста с `background-color` | `shape` `rect`, `fill` solid | `rgb()` → `#rrggbb`; альфа цвета → `fill.opacity` |
| 5 | `background-image: linear-gradient(...)` | `shape` `rect`, `fill` linear | направление только `to top/right/bottom/left` (0/90/180/270deg) → `from`/`to` долями бокса; 2–5 стопов, позиции только в `%`, без позиции — поровну |
| 6 | `border-radius` у фигуры | `shape.radius` | все четыре угла равны; px (`%` — от стороны квадратного бокса) / доля min; не больше половины меньшей стороны бокса |
| 7 | `border` (все стороны одинаковые, `solid`) | эффект `stroke` | `thickness` = ширина / доля min; бокс фигуры сужается на полширины рамки — обводка SVG идёт по оси контура, рамка CSS лежит внутри бокса |
| 8 | `box-shadow` (одна, не `inset`, без `spread`) | эффект `shadow` | `dx`, `dy` — px / доля min; `blur` = радиус размытия / 2 / доля min (σ гаусса); цвет → `color` + `opacity` |
| 9 | `opacity` (у элемента и всех предков до `#card`) | `opacity` слоя | произведение по цепочке предков; 1 — поле не пишется |
| 10 | элемент с текстом: бокс `position:absolute` + `left/top/width/height` px | `text`, `box` | бокс — по геометрии строк, правило «Бокс и выключка текста» ниже |
| 11 | `font-family` | `style.role` | первое имя семейства → роли с этой гарнитурой в `roles.json`; у Montserrat роль по насыщенности: ≥ 800 `display`, 700 `heading`, 600 `label`, ≤ 500 `body`; `Marck Script` → `accent`; чужая гарнитура — отказ (`problems`) |
| 12 | `font-size` px | `style.size` | px / доля Н |
| 13 | `font-weight` | `style.weight` | число как есть (100…900) |
| 14 | `font-style: italic` | `style.italic` | `true`; `normal` — поле не пишется |
| 15 | `color` | `style.color` | `rgb()` → `#rrggbb`; альфа — множителем в `opacity` слоя |
| 16 | `text-align` | `style.align` | `left`/`start` → `left`, `center`, `right`/`end` → `right`; уточняется геометрией строк (ниже) |
| 17 | `line-height` | `style.lineHeight` | px / кегль; `normal` → высота строки по `getClientRects` / кегль |
| 18 | `letter-spacing` | `style.tracking` | px / кегль; `normal` и 0 — поле не пишется |
| 19 | `text-transform` | `style.transform` | `uppercase` → `upper`; `none` — поле не пишется; `lowercase`/`capitalize` — отказ |
| 20 | `text-shadow` (одна) | эффект `shadow` у `text` | как строка 8 |
| 21 | строки текста (`Range.getClientRects`) | `lines` или привязка | строка, совпавшая с текстом продавца, — привязка (правило «Привязка» ниже), иначе — статические `lines` |
| 22 | элемент с текстом **и** собственным `background`/`border`/`box-shadow` (плашка с подписью) | два слоя: `shape` под ним и `text` над ним | `shape` — по строкам 4–8 по боксу элемента; `text` — тем же боксом, выключка по геометрии |
| 23 | порядок в DOM | `z` | `order × 10` (у текста плашки — `order × 10 + 1`); `order` — номер слоя в сцене после сортировки по `z-index` детей `#card` (`auto` = 0) и порядку DOM |
| 24 | `z-index` у ребёнка `#card` | порядок | ключ сортировки сцены; на более глубоких элементах — отказ |

### Бокс и выключка текста

Сборщик ставит базовую линию строки на `верх блока + i × интерлиньяж + интерлиньяж / 2 +
0,35 × кегль` (`svg.ts`), а Chromium — в середину строки по полуинтерлиньяжу. Для Montserrat
это одна и та же точка, поэтому достаточно совпасть **блоком строк**:

1. Блок строк по вертикали — от `центр первой строки − интерлиньяж / 2` высотой
   `число строк × интерлиньяж`; по горизонтали — объединение строк.
2. Кандидат — бокс элемента (border-box). По горизонтали подбирается выключка, при которой
   строки стоят в нём ровно (допуск 1,5 px): сначала та, что в `text-align`, затем `left`,
   `center`, `right`. По вертикали так же: `top`, `middle`, `bottom`; у подписи плашки — сначала
   `middle` (одна строка с `line-height` = высоте плашки подходит под обе).
3. Не подошла ни одна — бокс по этой оси сжимается до блока строк, выключка — из
   `text-align` (по вертикали — `top`).

Так `flex`-центровка, `padding` и `line-height` плашки переводятся без отдельных правил: важна
только итоговая геометрия.

### Привязка

Текст элемента (строки через пробел), сравнённый **без учёта регистра** и после схлопывания
пробелов, равен:

- короткому заголовку продавца → `bind: {kind:'text', slot:'title'}`;
- описанию продавца → `slot:'body'`;
- подписи свойства № i → `{kind:'prop', index:i, part:'label'}`;
- значению свойства № i → `{kind:'prop', index:i, part:'value'}`.

Привязанный слой строк не несёт; строки уходят в содержимое (`texts[slot]` или свойство,
переносы значения — `\n`) такими, как их снял Chromium: слова — продавца (это и сверено
привязкой), **регистр — тот, что сверстала модель** (решение владельца Q-H5: продавец написал
«чёрная вишня», модель — «Чёрная вишня», на карточке «Чёрная вишня»). Набранное прописными без
`text-transform` уходит в содержимое прописными. `transform` берётся из CSS. Строка, состоящая
из части слов продавца («Три цветных блока» из «Разделена на три цветных блока»), — статические
`lines`, не привязка.

## Запрещено

### Отказ транспилятора — элемент уходит в `scene.rejected`, карточка не транспилируется

| Что | Почему |
| --- | --- |
| `transform`, `rotate`, `scale`, `translate` | поворот и масштаб в словаре слоёв есть только как `rotate` бокса, перевод не однозначен |
| `filter`, `backdrop-filter`, `mix-blend-mode`, `clip-path`, `mask` | сборщик этого не рисует |
| `url(...)` в фоне, `img` кроме `frame.png` | внешних картинок в сборке нет (ADR-0012) |
| `<svg>`, `<canvas>`, `<video>`, `<iframe>`, `<object>`, `<script>` в `#card` | не слой словаря; скрипт — недоверенный код |
| псевдоэлементы `::before`/`::after` с `content` | текст и фигуры вне DOM не снимаются |
| `radial-gradient`, `conic-gradient`, `repeating-*`, несколько фонов через запятую | в словаре — сплошная и линейная заливка (`radial` не входит в форму ответа) |
| `border` разной толщины, цвета или стиля по сторонам; стиль не `solid` | `stroke` один на весь контур |
| `border-radius` с разными углами или эллиптический; `%` у неквадратного бокса | `radius` один и круговой |
| `box-shadow`/`text-shadow` из нескольких теней; `inset` | эффект `shadow` один и внешний |
| `text-decoration` (подчёркивание, зачёркивание) | нет в `TextStyle` |
| `writing-mode` кроме `horizontal-tb`; `-webkit-text-stroke` | нет в `TextStyle` |
| текст вперемешку с вложенными элементами (кроме `<br>`) | прогоны `TextRun` форма ответа не использует: один элемент — один стиль |
| `z-index` глубже детей `#card` | порядок слоёв — порядок DOM |

### Отказ на переводе — строка в `problems` у `toLayout`

Неизвестная гарнитура; цвет не `rgb()`/`rgba()`; градиент с углом вне 0/90/180/270, с числом
стопов вне 2–5 или с позицией не в `%`; одновременно `background-color` и градиент;
`box-shadow` со `spread`; `text-transform` кроме `uppercase`/`none`; `object-position` не по
центру; любое нарушение `validateLayout`; слово с буквами в статической строке, которого нет во
входных текстах продавца (заголовок, описание, свойства, `extra` — полное название, пожелания;
регистр и `ё`/`е` не различаются, чистые числа не проверяются, другая форма слова продавца —
его слово, правило ниже), и привязанное гнездо, легшее не словами продавца (`textMismatches`) —
шаг B5; символ статической строки вне шрифтов карточки (набор ниже) — шаг B7.

**Форма слова (Q-H6).** Слово модели — слово продавца, если у них общая основа: основа — само
слово или слово без одного окончания склонения (`ENDINGS` в `to-layout.ts`: `а`, `ы`, `ой`,
`ами`, `ого` …), если остаётся не меньше трёх букв. «замши» → «замша» (`замш`), «подошвой»
→ «подошва» (`подошв`), «кроссовками» → «кроссовки» (`кроссовк`). Другое слово того же корня
— отказ: «кресельный» не «кресло» (`кресельн` ≠ `кресл`), «комфортной» не «комфорт»;
короткие слова сравниваются целиком: «не» не «на».

**Знаки карточки (Q-H7).** Статическая строка (её набрала модель) состоит только из знаков,
которые рисуют шрифты проекта, — набор `DRAWN` в `to-layout.ts`, сверенный с таблицами
символов файлов `tools/card-pipeline/fonts/`:

- буквы латиницы (с Latin-1: `À–ÿ`) и кириллицы, цифры, пробел и неразрывный пробел;
- пунктуация: `. , : ; ! ? - ‐ – — « » “ ” „ ‘ ’ ' " ( ) [ ] / \ % № & + * # @ … ° × $ € ₽ ~ _ = < > | ² ³ ± · © ® ™ §`;
- значки Montserrat: маркеры `• ◆ ■ ▶`, стрелки `← → ↑ ↓ ↗ ↘`;
- значки шрифта значков `noto-sans-symbols-2.ttf` (`SYMBOL_GLYPHS` в `extract-browser.ts`):
  галочки `✓ ✔`, звёзды `★ ☆`, маркеры `● ○ ►`, стрелки `➔ ➜ ➤`.

Шрифт значков — подмножество Noto Sans Symbols 2 (OFL, лицензия рядом —
`noto-sans-symbols-2.license.txt`) ровно на `SYMBOL_GLYPHS`, снятое
`pyftsubset NotoSansSymbols2-Regular.ttf --unicodes=U+2713,U+2714,U+2605,U+2606,U+25CF,U+25CB,U+25BA,U+2794,U+279C,U+27A4`.
Знаков, которые есть в Montserrat, в нём нет намеренно: иначе Chromium и resvg брали бы их из
разных шрифтов. Chromium получает его гранями семейств карточки с `unicode-range`
(`FONT_FACES`), resvg — как ещё один файл каталога, в котором находит недостающий глиф. Знак вне
набора (снеговик `☃`, эмодзи) — отказ: Chromium нарисовал бы его системным шрифтом, сборка — пустым
квадратом. Привязанные строки — слова продавца — не проверяются, как и в сборке по библиотеке.

### Запрещено формой ответа, но транспилятор не отказывает

Модель обязана этого не писать (скил-жанр), но сцена снята в вычисленных px и переводится
верно, поэтому это не причина отказа:

- `flex`/`grid` у текстовых боксов — разрешены только как контейнеры без собственных стилей;
- единицы `em`, `rem`, `%`, `vw` — только `px`;
- потоковое позиционирование текстовых боксов — только `position:absolute` с
  `left/top/width/height` в px.

  `problems` (раздел «Отказ на переводе»).
