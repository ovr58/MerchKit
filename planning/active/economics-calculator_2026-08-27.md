# Калькулятор экономики: артефакт V-09 и синхронизация цифр в ТЗ

Status: ACTIVE (с 2026-08-27)

## Context

Три пункта ТЗ §11 (N стартовых баллов, цена генерации, состав пакетов) нельзя закрыть
одним числом: они зависят от вендора, курса, доли брака, структуры расходов и желаемой
прибыли. Пользователь попросил не «утвердить цифры словами», а собрать инструмент, в
котором цифры подставляются и сразу видно последствие, а кнопка «Утвердить» работает как
акт утверждения.

Расчётная база уже есть — [`UNIT_ECONOMICS.md`](../reference/UNIT_ECONOMICS.md). Артефакт
её не заменяет: он делает её проверяемой и пересчитываемой, а журнал операций даёт
сверку математики.

**Ограничение, которое нельзя обойти:** опубликованная страница не может править файлы
репозитория. Поэтому «применить в проекте» — это два шага: страница фиксирует решение в
себе, Claude Code переносит его в `TZ.md` и `UNIT_ECONOMICS.md`.

## Цель

Опубликовать V-09, включить ему сохранение и провести первую синхронизацию утверждённых
цифр в ТЗ.

## Шаги

- [x] Собрать страницу: вендоры, параметры генерации, прайс в баллах, пакеты, постоянные и
      единоразовые расходы, цель по прибыли
- [x] Графика: структура себестоимости, сравнение вендоров, кривая безубыточности, отчёт по
      статьям, схема движения денег и баллов (палитра проверена валидатором `dataviz`)
- [x] Журнал операций с пошаговой арифметикой + выгрузка JSON/CSV
- [x] Зарегистрировать как [V-09](../../docs/VISUALS.md#v-09), исходник — `docs/design/economics/`
- [ ] **Опубликовать артефактом** — 2026-08-27 сервис вернул `deploy 403` на четырёх попытках,
      включая публикацию без capabilities. Повторить позже
- [ ] При публикации объявить `capabilities: {artifact, downloads}` — без них кнопка
      «Утвердить» не сохранит решение в артефакт, а журнал живёт только в браузере
- [ ] Пользователь жмёт «Утвердить цифры» → Claude читает артефакт и переносит решение:
      `TZ.md` §11 (закрыть три пункта), `UNIT_ECONOMICS.md` (пересчитать), артборды
      [V-08](../../docs/VISUALS.md#v-08) (цифры на профиле)
- [ ] Ответить на открытый вопрос: чем платим Google Cloud — от этого зависит, остаётся ли
      Google опорным вендором расчёта

## Verification

- Страница открывается локально двойным кликом и считает без сети (кроме шрифтов).
- Журнал: запись «Утверждено» содержит входные параметры, результат и арифметику, по
  которой ручной пересчёт даёт те же числа.
- После синхронизации цифры совпадают в трёх местах: артефакт, `TZ.md` §11, артборды V-08.
- Убыточный сценарий подсвечивается: поставить вендором Nano Banana Pro → маржа «Про»
  уходит в минус и страница говорит об этом прямым текстом.

## Не входит

Выбор вендора продукта — остаётся за [ADR-0005](../../docs/adr/0005-ai-provider-abstraction.md);
здесь вендоры лишь варианты расчёта. Эквайринг ([B4](../BACKLOG.md)) — вне scope версии,
в модели присутствует только как процент от выручки.
