**Отдельно, чтобы не всплыло второй раз:** «пусть вырез сделает сама модель изображений» —
проверено и отклонено. Оба пути через модель (товар на прозрачном фоне отдельной генерацией ·
редактирование сцены) возвращают **новые пиксели**, а слою `cutout` нужен **тот же растр**,
что в `frame`, — иначе вместо «текст уходит за товар» получается двойной контур. Подробно —
ADR-0014, раздел Context.

## Форма схемы (шаг B0)

Эскиз, а не готовый DDL: имена и ограничения уточняются при написании миграции, но состав
полей и то, что **вычисляется**, а не хранится, — уже решено.

```
card_layouts
  id             text primary key         -- совпадает с layout.id в разборе
  title          text not null
  layout         jsonb not null           -- CardLayout по схеме A1
  source         text not null            -- откуда образец (файл, URL, «собран вручную»)
  category_id    text references categories (id)
  marketplace_id text references marketplaces (id)  -- тег, а не ось библиотеки
  preset_id      text references presets (id)       -- сценарий показа, FR-08
  uses_logo      boolean not null default false
  hands_hidden   boolean not null default false     -- признак из K-4
  is_fallback    boolean not null default false
  created_at     timestamptz not null default now()

  -- вычисляется из layout, отдельным полем не хранится:
  --   prop_slots — число привязок kind = 'prop'
  --   frames     — максимальный index привязки kind = 'frame' плюс единица
  --   has_cutout — есть ли слой type = 'cutout'
  --   aspect_w/h — из layout.canvas
  -- Способ (генерируемая колонка или view) — за исполнителем; требование одно:
  -- значение не может разойтись с макетом.

generation_cards
  generation_id uuid primary key references generations (id) on delete cascade
  layout_id     text references card_layouts (id)   -- кого выбрал подбор
  layout        jsonb not null                      -- СНИМОК: что реально собиралось
  content       jsonb not null                      -- тексты, свойства, ссылки на ассеты
  font_map      jsonb not null                      -- роль → гарнитура (для B7)
  assembled_at  timestamptz not null default now()
```

**RLS:** `card_layouts` политик не заводит — читает только service-role (подбор, превью и
сборка серверные). `generation_cards` читает владелец своей генерации, пишет service-role.

**Тест базы обязателен:** в библиотеке есть хотя бы один `is_fallback`. Прецедент — проверка
полноты `card_font_roles` в `supabase/tests/database/card_assets.test.sql`.

## Контракт раннера выреза (шаги B4.0, B4)

```
cutout-runner:  { frame: ImageRef } → { mask: ImageRef } | null
```

Маска — того же размера, что кадр. `null` — штатный исход: слой `cutout` снимается правилом
K-3, карточка собирается без него. Реализации сменные (wasm в изоляте · браузер · нативный
рантайм на своём сервере), файл модели между ними переносится байт в байт.

**B4.0 — замер, а не выбор по вкусу.** На выходе таблица: модель · лицензия **со ссылкой на
первоисточник** · память и время в локальном рантайме функций · то же в браузере · качество
кромки на наших кадрах. Лицензия проверяется отдельно от кода: у части моделей этого класса
код открыт, а веса некоммерческие.

## Деньги и прогоны

- **Платный прогон — только по явному разрешению пользователя.** В фазе B платного нет ничего,
  кроме сквозной проверки на живом вендоре в самом конце; разведка B4.0 и теги B2.0 — офлайн.
- **Офлайн-проходы моделью — через Batch API**, как `parse.mts`: вдвое дешевле, ответа никто
  не ждёт.
- **Логи вендора включаются ДО платного прогона**, иначе выводы о времени и стоимости брать
  неоткуда.
- Ключи лежат в `.env` (`AI_PROVIDER_*` — продуктовый вендор, ключ Anthropic — офлайн-инструменты).
  **Значения не читать и никуда не копировать**; проверять можно только наличие имени.
- Облачный Supabase проекта — **стейдж**, не прод. Так его и называть в отчётах.

## Чего не делать

- **Не расширять язык макета «на будущее».** Словарь растёт только по найденной нехватке —
  так добавились `radial`, `stroke`, поворот, прогоны. Нужна новая сущность — сначала
  показать образец, который без неё не выражается.
- **Не переделывать фазу A.** Разбор, базы иконок и шрифтов, сборщик и валидатор закрыты и
  проверены гейтом A3 на 34 макетах. Нашлась ошибка — минимальная правка в одном месте.
- **Не менять ТЗ и спецификацию под реализацию.** Не сходится требование с кодом — это вопрос
  пользователю, а не повод переписать требование.
- **Не пушить и не деплоить без явной команды пользователя.** Прямые коммиты в `main`
  запрещены и блокируются хуком.
- **Развилку, тянущую на отдельный план, — в `planning/BACKLOG.md`** готовым промптом, а не
  в код «заодно».

## Приёмка фазы

- **Гейт A3 не ломается:** пересборка 34 макетов после переезда библиотеки в базу даёт те же
  PNG. Прецедент проверки — переезд иконок и шрифтов в A5 дал побайтово те же файлы.
- **Текст дословен:** на 20 сборках подряд заголовок и описание совпадают с заданными
  побайтово (критерий из плана, раздел Verification).
- **Файл точно под профиль площадки** — после возврата `describeProfileMismatch` к равенству.
- **Подбор не падает никогда:** на вводе без единого совпадения по тегам возвращается
  универсальный макет.
- **Ничто не пропадает молча:** если свойств больше, чем модулей в макете, превью называет
  отсечённые и причину, а не показывает кадр без них.
- **Пересборка воспроизводима:** правка макета в библиотеке не меняет того, что соберётся у
  старой генерации.
- Каждый закрытый шаг отмечается в плане `card-assembly-pipeline_2026-08-31.md` в том же
  изменении; строка в [`planning/INDEX.md`](../INDEX.md) обновляется вместе с перемещением
  файлов.
