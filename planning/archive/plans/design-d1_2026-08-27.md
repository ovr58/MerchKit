# D1 — дизайн-канвас: экраны аккаунта и профиля

Status: DONE (выполнено 2026-08-27)

## Context

Генеральный план ([`00_GENERAL_PLAN.md`](../reference/00_GENERAL_PLAN.md), раздел «Дизайн»)
запрещает стартовать вёрстку вехи, пока её артборды не утверждены. Веха **M2 — Аккаунт**
блокирована заходом **D1**. Канвас регистрируется в [`VISUALS.md`](../../docs/VISUALS.md)
как [V-08](../../docs/VISUALS.md#v-08), а [V-06](../../docs/VISUALS.md#v-06) остаётся
текстовым перечнем состояний и обязан ему соответствовать.

Два пробела закрываются в этом же заходе, иначе профиль нечем наполнить:

- **Палитра.** В [V-05.1](../../docs/VISUALS.md#v-05) стоял `TODO(пользователь)` про
  брендбук. Пользователь дал референс: `github.com/leoMirandaa/shadcn-landing-page` —
  зелёная тема shadcn (`--primary: 142.1 76.2% 36.3%`), радиус `0.5rem`.
- **Цифры.** N стартовых баллов, цена генерации и состав пакетов стояли открытыми
  вопросами ТЗ §11. Пользователь попросил посчитать реальную экономику по коммерческому
  прайсу Google → [`UNIT_ECONOMICS.md`](../reference/UNIT_ECONOMICS.md).

## Цель

Опубликовать дизайн-канвас с утверждаемыми десктопными артбордами экранов вехи M2 и
зарегистрировать его как V-08.

## Verification

- Каждый экран US-02, US-03, US-E7 имеет артборд, включая состояния ошибок полей.
- Контраст текста ≥ 4.5:1 (NFR-07); у каждого поля видимая подпись.
- Цифры на артбордах совпадают с `UNIT_ECONOMICS.md` и помечены как неутверждённые.

## Не входит

Мастер генерации, каталог, результаты, ошибки US-E1…US-E5 — это заход **D2** перед M4.
Мобильные артборды: по NFR-09 они обязательны для мастера и каталога, то есть тоже D2.
