  `npm run cards:apply-layout-tags`; последней нужен `tools/card-pipeline/layout-tag-proposals.json`
  (в `.gitignore`) — копировать из основного дерева.

  `npm run build` — каждая отдельной командой со своим кодом выхода. **`npm run lint` не видит
  `supabase/functions/**`** (B27): серверные файлы — временным конфигом oxlint без
  `ignorePatterns` (`{"plugins":["typescript","oxc"],"ignorePatterns":[]}`) по изменённым файлам.
- Тесты инструментов на `node --test` — по глобу в кавычках, не каталогом.
- Сообщение коммита — файлом и `git commit -F`: хук читает всю строку команды.
- `.env` — значения не читать; проверять только наличие имени. Ключи вендора — `AI_PROVIDER_*`;
  секрет выреза (`CUTOUT_ENDPOINT`, `CUTOUT_SECRET`) **не заведён** — воркер собирает без выреза.
- **Коробка (VPS сервиса выреза) на паузе по решению владельца с 2026-10-03.** Исполнители её не
  вызывают и не реанимируют; понадобится — запрос владельцу отдельным сообщением.
