  `npm run build` — каждая отдельной командой со своим кодом выхода; красный линт в цепочке
  `A && B` прячет вторую половину.

  `MODULE_NOT_FOUND`).
- Сообщение коммита — файлом и `git commit -F`: хук читает всю строку команды, упоминание
  `.env` в тексте валит коммит.
- `.env` — значения не читать и не копировать; проверять только наличие имени. Ключи вендора —
  `AI_PROVIDER_*`; секрет выреза для вызывающей стороны (`CUTOUT_ENDPOINT`, `CUTOUT_SECRET`)
  **ещё не заведён** — без него воркер обязан собирать без выреза (шаг B7.1), значение даёт
