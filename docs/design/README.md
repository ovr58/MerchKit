# docs/design/ — исходники графических артефактов

> **Правило (решение пользователя от 2026-08-27):** все графические артефакты проекта —
> артборды дизайн-канваса, интерактивные страницы-калькуляторы, любая другая графика
> сложнее схемы — **хранятся здесь, в репозитории**, а не только в опубликованном артефакте.
>
> Это не отменяет [ADR-0004](../adr/0004-single-visual-artifact.md): реестр и адресация
> остаются в [`../VISUALS.md`](../VISUALS.md). Здесь лежат **исходники**, там —
> **реестр `V-NN` и ссылки на опубликованное**. Новый артефакт заводится строкой в реестре
> `VISUALS.md` и папкой здесь — в одном изменении.

## Как это работает

**Дизайн-канвас (`*.dc.html` + `canvas.json`).** Это исходники артбордов Claude Design.
Правка идёт двумя путями:

- **В артефакте** — клик по элементу, панель свойств, `Save` публикует новую версию для всех.
  После такой правки исходники здесь устаревают: их пересобирают выгрузкой из артефакта
  (`seed-canvas.mjs --extract`) по процедуре скила `design`.
- **Из репозитория** — правится `gen.mjs` (он генерирует все артборды), затем канвас
  пересобирается и переиздаётся на тот же URL.

При расхождении **прав опубликованный артефакт**: именно в нём макеты утверждаются.
Файлы здесь — воспроизводимый исходник и страховка, а не второй источник правды.

**Самодостаточные страницы (`economics/`).** Обычный HTML: открывается двойным кликом
локально и публикуется артефактом. Внутри страницы состояние хранится в блоке
`<script type="application/json" id="mk-state">` — опубликованная версия страницы и есть
её база данных.

## Чего здесь не держим

- **Схем.** Mermaid-диаграммы живут текстом в `VISUALS.md` — правило ADR-0004.
- **Скриншотов и растра.** Они в [`../assets/`](../assets/) с именем по ID визуала.
- **Собранных артефактов дизайн-канваса** (`*-canvas.html`, ~2 МБ): это упакованный
  редактор, а не исходник. Собирается заново из файлов этой папки.
