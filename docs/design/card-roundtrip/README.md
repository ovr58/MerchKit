# V-13 — Пересборка трёх образцов (исходник)

Реестр и описание визуала — [`../../VISUALS.md`](../../VISUALS.md#v-13).

## Почему исходник неполный

В `peresborka-obrazcov.src.html` на месте девяти картинок стоят плейсхолдеры вида
`__IMG_JACKET_ORIG__`. Сами файлы лежат в
[`../../assets/cardsforsysprompt/`](../../assets/cardsforsysprompt/): три оригинала (V-10) и
шесть сборок гейта A3, которые кладёт туда `npm run cards:roundtrip`. Держать их вторую копию,
раздутую base64 до двух мегабайт, значит нарушить правило «крупные исходники в репозиторий не
кладутся» ради дубля того, что уже есть рядом.

## Сборка перед публикацией

Из корня репозитория:

```bash
node docs/design/card-roundtrip/build.mjs > /tmp/peresborka-obrazcov.html
```

Скрипт уменьшает картинки до 340 px по ширине тем же `resvg`, что собирает карточки.
Собранный файл — около 2,3 МБ, публикуется инструментом `Artifact` **по тому же URL**
(параметр `url`), иначе заведётся отдельная страница. Собранный файл в репозиторий не кладётся.

## Правки

Править `peresborka-obrazcov.src.html`, плейсхолдеры не трогать, затем пересобрать и переиздать.
Правка собранного файла потеряется при следующей сборке. Если менялись сами сборки гейта —
сначала `npm run cards:roundtrip`, потом сборка страницы.
