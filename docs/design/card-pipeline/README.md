# V-11 — Конвейер карточки (исходник)

Реестр и описание визуала — [`../../VISUALS.md`](../../VISUALS.md#v-11).
Опубликованная страница: https://claude.ai/code/artifact/a6e753e8-8f25-4d98-9786-01a01ce98c25

## Почему исходник неполный

В `konveyer-kartochki.src.html` на месте образцовой карточки стоит плейсхолдер
`%%CARD_B64%%`. Сама картинка уже лежит в репозитории — это
[`../../assets/cardsforsysprompt/пример карточки верхней одежды.png`](../../assets/cardsforsysprompt/)
(V-10). Держать её вторую копию, раздутую base64 до мегабайта, значит нарушить правило
«крупные исходники в репозиторий не кладутся» ради дубля того, что уже есть рядом.

## Сборка перед публикацией

Из корня репозитория, Git Bash:

```bash
B64=$(base64 -w0 "docs/assets/cardsforsysprompt/пример карточки верхней одежды.png")
awk -v b64="data:image/png;base64,$B64" \
  '{gsub(/%%CARD_B64%%/, b64); print}' \
  docs/design/card-pipeline/konveyer-kartochki.src.html > /tmp/konveyer-kartochki.html
```

Собранный файл — около 1,1 МБ, публикуется инструментом `Artifact` **по тому же URL**
(параметр `url`), иначе заведётся отдельная страница. Собранный файл в репозиторий не
кладётся.

`awk` здесь безопасен: алфавит base64 не содержит ни `&`, ни обратного слеша, поэтому
подстановка не портит данные.

## Правки

Править `konveyer-kartochki.src.html`, плейсхолдер не трогать, затем пересобрать и переиздать.
Правка собранного файла потеряется при следующей сборке.
