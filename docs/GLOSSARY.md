# GLOSSARY.md — словарь сокращений и технических понятий

> Дополняет [`CONTEXT.md`](../CONTEXT.md). Здесь — **сокращения** (аббревиатуры) и **технические
> понятия**, которые может не понять джуниор-разработчик или неподготовленный человек. Доменные
> термины проекта (со значением-в-словах-проекта) живут в `CONTEXT.md`; отсюда на них — ссылка.
>
> **Правило использования (для Claude и людей):** при **первом** употреблении термина в ответе/
> схеме/плане/комментарии — расшифровка кратко в скобках. **Сокращения — всегда** (WS → WebSocket).
> **Понятие** — если его может не понять джун. Перед вводом сверяйся с этим словарём (термин уже
> вводили или нет); новое — добавляй строкой сюда.

## Формат

> **СОКР** (англ. Full Form) — краткое объяснение по сути. `→ CONTEXT.md`, если это доменный термин.

## Словарь

> _Заполняй под проект. Ниже — пример записи; замени/дополни своими терминами._

**WS** (WebSocket) — протокол постоянного двустороннего соединения поверх одного TCP; типичный
push-транспорт сервер→клиент (в отличие от запрос/ответ HTTP/gRPC).

**ADR** (Architecture Decision Record) — запись об архитектурном решении: один файл = одно
необратимое/дорогое-к-откату решение с контекстом, самим решением и последствиями. Нужен, чтобы
решение не переоткрывали заново каждой новой сессией. Правила — `docs/adr/README.md`.

**MCP** (Model Context Protocol) — открытый протокол, по которому AI-агент подключает внешние
инструменты и источники данных (файлы, БД, API) единообразно, не зашивая их в сам агент.
Поддерживается Claude Code, Harvi Code и Copilot — единственная возможность, общая для всех трёх.

**Автозагрузка контекста** (always-on context) — механизм хоста, который кладёт содержимое
определённого файла в контекст **каждой** сессии без ручного прикрепления. Ключевой факт для
кросс-AI работы: правило из файла, который хост не автозагружает, на практике не исполняется.
У каждого хоста имя такого файла своё: `CLAUDE.md` (Claude Code), `AGENTS.md` (Harvi Code),
`.github/copilot-instructions.md` (Copilot).

**`@import`** — синтаксис `CLAUDE.md`, подтягивающий содержимое другого файла (`@AGENTS.md`) в
автозагружаемый контекст. Позволяет держать канон в одном месте вместо копипасты текста по
файлам-адаптерам. *Только Claude Code*: Copilot и Harvi импортов не поддерживают.

**Fast-merge** — мёрж боковой ветки в `main` сразу после self-review, без ожидания апрува
пользователя. Привилегия доверенной полосы (`→ CONTEXT.md`), не общее правило.

**Страховочный контур** — запасной маршрут запросов Claude Code на Anthropic-совместимый
эндпоинт стороннего провайдера, когда лимиты подписки исчерпаны. Опознаётся машинно: переменная
`ANTHROPIC_BASE_URL` указывает не на `api.anthropic.com`. Модель там не Opus по подписке, поэтому
сессия на контуре идёт консервативной полосой (ADR-0002). Носитель правила — контур хуков, если
модуль включён; карта контура — [`docs/HOOKS_TEMPLATE.md`](HOOKS_TEMPLATE.md), он остаётся в
любом профиле.

**Harvi Code** — стороннее VS Code-расширение-AI-агент (паблишер KristianShin) с выбором модели,
включая Opus. Третий поддерживаемый хост темплейта наряду с Claude Code и Copilot. `→ CONTEXT.md`
(AI-хост).

**SRS** (Software Requirements Specification) — документ требований к ПО по стандарту
ISO/IEC/IEEE 29148. В нашем темплейте его роль делят два файла: `docs/TZ.md` (что и зачем) и
`docs/SPEC.md` (как). `→ CONTEXT.md` (ТЗ, Спецификация).

**PRD** (Product Requirements Document) — продуктовый документ требований: зачем продукт,
кому и какую задачу решает. Соответствует нашему `docs/TZ.md`; отдельного файла `PRD.md` мы
не заводим. `→ CONTEXT.md` (ТЗ).

**Fit criterion** (критерий соответствия, из шаблона Volere) — измеримая проверка, по которой
видно, выполнено требование или нет. Превращает «должно быть удобно» в проверяемое
утверждение. Без него требование не проверяемо, а значит и не требование.

**Given/When/Then** — формат критерия приёмки: *дано* исходное состояние, *когда* произошло
действие, *тогда* наблюдается результат. Написанный так критерий превращается в тест почти
дословно — стык с TDD и `verification-before-completion`.

**INVEST** — набор признаков хорошей пользовательской истории: Independent, Negotiable,
Valuable, Estimable, Small, Testable (независима, обсуждаема, ценна, оценима, невелика,
проверяема).

**Non-goals** (не-цели) — то, что **могло бы** разумно быть целью проекта, но сознательно ею
не является. *Граница:* это не отрицание качеств («не должно падать») — это отброшенные цели.

**Test double** (тестовый дублёр) — зонтичное английское название для подставных реализаций в
тестах: stub (отдаёт заготовленный ответ), fake (упрощённая рабочая реализация), mock
(проверяет, как его вызывали). У нас термин по-русски и с проектным значением —
`→ CONTEXT.md` (Тестовый дублёр). Не путать с «файлом-дублёром» (ADR-0004) — там это
запрещённая копия артефакта.

**Contract test** (контрактный тест) — тест, который прогоняют обе стороны границы, чтобы
поймать расхождение на самой границе, а не на интеграции. Инструменты вроде Pact
автоматизируют это между сервисами; внутри одного приложения роль играет обычный тест против
замороженного интерфейса. `→ CONTEXT.md` (Контрактный тест).

**C4** — модель архитектурных схем из четырёх уровней: Context (система и внешний мир),
Container (запускаемые части и хранилища), Component (устройство части), Code. Мы рисуем L1 и
L2; L4 не заводим — устаревает быстрее, чем пишется.

**arc42** — шаблон структуры архитектурной документации из 12 разделов. Скелет `docs/SPEC.md`
— его сжатая версия; разделы «решения» и «глоссарий» у нас вынесены в `docs/adr/` и
`CONTEXT.md` и в спецификации не дублируются.

**Mermaid** — язык описания диаграмм текстом (```mermaid-блок в Markdown), который редакторы
и GitHub рендерят в картинку. Нужен затем, что текст диффится и правится точечно, а
экспортированная картинка — нет. Формат схем в `docs/VISUALS.md`.

**WCAG** (Web Content Accessibility Guidelines) — стандарт доступности интерфейсов с тремя
уровнями соответствия: A (базовый), **AA** (то, что почти всегда подразумевают под
«соответствием WCAG» в законах и договорах), AAA (максимальный).

**ASVS** (Application Security Verification Standard, OWASP) — стандарт проверки безопасности
приложений с тремя кумулятивными уровнями: L1 (базовый), **L2** (рекомендуемый для
большинства и для любых чувствительных данных), L3 (критичные системы).

**HIG** (Human Interface Guidelines) — руководство Apple по проектированию интерфейсов под её
платформы. Соответствие ему проверяется на ревью App Store.

**RN** (React Native) — фреймворк для мобильных приложений на React с нативным рендерингом.

**SPA** (Single Page Application) — веб-приложение, которое отрисовывается в браузере одной
страницей без перезагрузок. *Граница:* противопоставляется SSR — серверной отрисовке,
нужной, когда важны SEO и первая отрисовка.

**SSR / SSG / ISR** (Server-Side Rendering / Static Site Generation / Incremental Static
Regeneration) — три способа отдать страницу готовой: отрисовать на сервере на каждый запрос ·
собрать заранее при сборке · пересобирать заранее собранное по мере устаревания.

**Идемпотентность** (idempotency) — свойство операции давать один и тот же результат, сколько
бы раз её ни повторили. В биллинге держится **ключом идемпотентности**: уникальной пометкой
события, по которой повтор узнаётся и не выполняется второй раз. *Граница:* «повторный вызов
не сработал» — не ошибка, а штатный исход. `→ CONTEXT.md` «Журнал операций».

**Плюс-адресация** (plus addressing, sub-addressing) — приём почтовых провайдеров, при котором
письмо на `ящик+любое@домен` приходит в `ящик@домен`. Gmail вдобавок игнорирует точки в
локальной части. Практическое следствие: один почтовый ящик даёт неограниченное число
внешне разных адресов — и обходит любой барьер, построенный на «один email — один аккаунт».

**Начертание** (font style/weight) — конкретный файл гарнитуры: Montserrat Bold и Montserrat
Regular — два начертания одной гарнитуры. *Граница:* не «шрифт вообще» и не переменный шрифт
(один файл на все насыщенности) — переменные наш растеризатор не поддерживает, поэтому в базе
по файлу на насыщенность. `→ CONTEXT.md` «База шрифтов».

**OFL** (SIL Open Font License) — свободная лицензия на шрифты: разрешает коммерческое
использование и встраивание, требует распространять текст лицензии вместе с файлами и
запрещает продавать сами шрифты отдельно. Поэтому текст лицензии хранится в базе рядом со
шрифтом, а не только ссылкой.

**OTel** (OpenTelemetry) — открытый вендор-нейтральный стандарт и набор SDK для сбора логов,
метрик и трейсов. Не бэкенд: данные собирает и передаёт, хранит и показывает — отдельная
система (Grafana Cloud, SigNoz и т.п.), которую можно сменить без переписывания
инструментирования. `→ CONTEXT.md` (Observability).

**PII** (Personally Identifiable Information, персональные данные) — любые данные, по которым
можно прямо или косвенно установить конкретного человека (имя, email, IP, идентификатор
устройства). Определяет, что можно писать в события, логи и session replay без согласия и
маскирования. `→ docs/TZ.md` NFR-06.

**SDK** (Software Development Kit) — библиотека вендора, которую подключают в приложение для
отправки данных в его систему (например, `posthog-js`, `@sentry/react`). В темплейте SDK
вызывается только через тонкий слой абстракции, а не напрямую из обработчиков — иначе смена
вендора требует переписать весь код инструментирования.

**Drop-off** (отвал) — шаг сценария, на котором теряется больше всего пользователей. Частный
случай воронки (funnel). `→ CONTEXT.md` (Funnel / drop-off).

**DTCG** (Design Tokens Community Group, W3C) — рабочая группа и её формат JSON для описания
дизайн-токенов. Ценность в переносимости: один и тот же файл читают Figma-экспортёры, Penpot,
Tokens Studio и Style Dictionary, поэтому смена инструмента дизайна не переписывает пайплайн
токенов. `→ CONTEXT.md` (Дизайн-токен).

**UI-кит** — библиотека готовых компонентов и стилей для редактора дизайна (Figma, Penpot),
которую берут за основу вместо рисования с нуля. **Годен только парный кит:** к нему должна
существовать кодовая библиотека той же системы, а в самом ките — **переменные**, а не залитые
значения. Кит без переменных — картинка: токены из него не выгружаются.

**Style Dictionary** — открытый конвертер дизайн-токенов: один DTCG-источник → CSS-переменные,
конфиг Tailwind, JS/TS, Swift, Compose, XAML. Нужен затем, что токен экспортируется один раз, а
приёмников у него в проекте несколько.

**Изолят** (isolate) — отдельный экземпляр движка JavaScript, в котором Edge Function исполняет
один запрос, со своими пределами памяти и процессорного времени. Превысил предел — платформа
убивает изолят и отвечает `546` `WORKER_LIMIT` (или `503` с пустым телом); отсюда «тяжёлый
макет» → `CONTEXT.md`.

**Headless Chromium** (браузер без окна) — движок браузера Chromium, запущенный программой без
экрана: он раскладывает страницу (каскад стилей, переносы строк, обмер текста) так же, как
обычный браузер, а программа читает результат. Запускается через Playwright (библиотеку
управления браузером). У нас — снятие сцены HTML на коробке выреза. `→ CONTEXT.md` (Сцена HTML).

**Транспилятор** (transpiler) — программа, переводящая описание с одного языка на другой того же
уровня, а не в машинный код. У нас — перевод вёрстки HTML/CSS в язык слоёв карточки.
`→ CONTEXT.md` (Транспилятор HTML → слои).

**Round-trip вёрстки** (проход туда и обратно) — проверка перевода без потери: одну и ту же
карточку снимают скриншотом Chromium и собирают по слоям после транспилятора, потом считают долю
различающихся пикселей. Выше порога — значит, транспилятор что-то потерял.

**bytea** — тип Postgres для двоичных данных. Через PostgREST (REST-слой Supabase над базой)
приходит строкой `\x…` в шестнадцатеричной записи — её надо декодировать в байты.
