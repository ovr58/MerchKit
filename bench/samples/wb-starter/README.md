## Примечания

- Все образцы в формате `.jpg` (скриншоты карточек товаров)
- Названия файлов содержат временные метки сбора
- Этот набор **не покрывает** требования всех маркетплейсов — проверка требований Ozon и Я.Маркета переезжает на этап пополнения
- Офлайн-конвейер разбора строится как процедура, а не как разовая загрузка

## Связь с планом

> **A6. Стартовый набор — ~21 образец, все с Wildberries.** Отбирает пользователь сам, по нескольким разделам WB; разделов там много, и полный обход поля — работа для прода. **Цель набора прежняя — прогнать конвейер целиком, а не получить разнообразие.**
