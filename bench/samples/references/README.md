# Референсы сочинения карточки — куда класть

Образцы карточек лидеров выдачи, которые модель сочинения видит рядом с кадром товара
([ADR-0019](../../../docs/adr/0019-html-authoring-transpiled-to-layers.md), п. 7). Положил образец
сюда и выполнил `npm run cards:references -- push` — следующая карточка той же площадки и
категории может опереться на него. Код не правится.

## Раскладка

```
bench/samples/references/<площадка>/<категория>/<файл>.jpg
```

- **Площадка** — id из справочника `marketplaces`: `ozon`, `wildberries`, `yandex`.
- **Категория** — id из справочника `categories` (модуль `catalog-taxonomy`): `clothing`,
  `accessories`, `food`, `beauty`, `tech`, `home`, `other`.
- Вложенные папки ниже категории можно заводить — их имена станут тегами образца.
- Формат — JPEG, PNG или WebP, **не больше 2 МБ**: больший файл инструмент отклонит с подсказкой
  ужать. Скриншот карточки целиком, без интерфейса площадки вокруг.

Тот же файл второй раз не заводится: путь в бакете содержит хеш содержимого. `pull` выкладывает
каталог сюда же под именами-хешами.

Стартовое наполнение — `bench/samples/wb-starter/` (31 образец Wildberries) — `push` берёт
оттуда сам, сопоставляя разделы WB категориям (`WB_STARTER_CATEGORIES` в
`tools/card-pipeline/references.mts`).

## Как выбирается

Не больше четырёх на карточку: сначала та же площадка и категория, затем та же категория, затем
любые; внутри — ротация по идентификатору генерации, чтобы соседние карточки получали разные
наборы. Первый — ведущий: модель берёт его композицию за основу. Код —
`supabase/functions/_shared/card-layout/html/references.ts`.
