Хук `.claude/hooks/protect-irreplaceable.js` разбирает **строку команды целиком**, а не её
смысл. Сообщение коммита в `-m "…"` или heredoc, где упомянуты `.env`, `cp`, `rm`, — часть
строки, и хук валит `git commit` (exit 2), хотя ничего не удаляется.

**Why:** даже коммит, который чинит сам хук, может быть заблокирован хуком, если текст
сообщения описывает команду вроде `cp .env.example .env`. Замер по корпусу сессий: `git commit
-m` — 105 вызовов, **10 отказов (10%)**; `git commit -F` — 481 вызов, 9 отказов (**2%**) —
разница в форме передачи сообщения, а не в содержании коммитов.

**How to apply:** сообщение коммита, где есть имена секретов или команды удаления, писать
инструментом записи файла во временный файл и коммитить `git commit -F <файл>` — тот же приём,
что в [[bash-backticks-eat-markdown-ids]]. Хук не обходить и не отключать. Проверка хука —
`node --test .claude/hooks/protect-irreplaceable.test.js` (каталог аргументом Node может молча
не запускать ничего — указывать файл теста явно).
