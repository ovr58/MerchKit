`Edit`/`Write` отказывают, если файл не был прочитан инструментом `Read` в текущей сессии —
`File has not been read yet. Read it first before writing to it.` Тот же отказ бьёт и после
чтения, если файл успел измениться снаружи (форматтер, линтер, другой процесс) —
`File has been modified since read, either by the user or by a linter`. В обоих случаях правку
надо начинать заново с `Read`.

**Why:** замер по корпусу сессий (215 транскриптов, добыча парсером): 99 отказов `Edit` + 13
`Write` + 13 отказов по устаревшему чтению = **125** — самая частая причина отказа инструмента
в корпусе после лимита длины команды.

**How to apply:** перед `Edit`/`Write` файл должен быть прочитан в этой же сессии, и после
этого чтения его не должен был трогать никто другой (в т.ч. автосейв IDE, pre-commit форматтер,
параллельная сессия в том же дереве). Отказ по обеим причинам чинится одинаково — повторный
`Read`, а не повтор той же правки вслепую.
